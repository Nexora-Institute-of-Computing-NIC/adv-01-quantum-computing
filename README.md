# Quantum Computing

**Category:** Advanced Course - Nexora Institute of Computing
**Time commitment:** 60 hours (theory + labs) - **Level:** Post-graduate

> **Status:** Scaffolded. Content in progress. See PLAN.md for the outline.

## Overview

An advanced course on quantum computation - qubits, gates, algorithms, and the reality of near-term quantum hardware.

## Prerequisites

Linear algebra (MA102), discrete maths (MA101), basic algorithms (CS301).

## What makes this "advanced"

This course goes **beyond** the 80-subject core curriculum. It assumes you have completed the prerequisites and dives into material typically found in graduate programmes or advanced industry practice.

- labs/ - hands-on labs
