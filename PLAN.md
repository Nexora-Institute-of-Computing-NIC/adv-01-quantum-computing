# Quantum Computing - PLAN

**Category:** Advanced Course

## Syllabus

### Unit 1 - Quantum Foundations
1. The qubit and state vector
2. Superposition and measurement
3. Bloch sphere
4. Entanglement
5. No-cloning theorem

### Unit 2 - Quantum Gates and Circuits
1. Single-qubit gates
2. Multi-qubit gates
3. Circuit model
4. Universality
5. Simulating small circuits

### Unit 3 - Quantum Algorithms
1. Deutsch-Jozsa
2. Bernstein-Vazirani
3. Grover's search
4. Shor's factoring (overview)
5. Quantum Fourier transform

### Unit 4 - Hardware and Noise
1. Superconducting qubits
2. Trapped ions
3. Photonic qubits
4. Decoherence and noise
5. Error mitigation

### Unit 5 - Quantum Error Correction and Applications
1. Classical error correcting codes
2. Quantum repetition code
3. Surface codes
4. Near-term applications
5. Post-quantum cryptography
